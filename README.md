# Blog Preview Card

A responsive blog preview card built from a Frontend Mentor design.

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Custom Properties
- Semantic HTML

## What I Learned

- Using semantic HTML elements
- Understanding Figma layout hierarchy
- Building nested Flexbox layouts
- Controlling spacing with gap
- Understanding browser default margins
- Using fit-content
- Understanding box sizing
- Matching dimensions from a design system
- Using DevTools to investigate layout differences

## What I Improved

I learned not to fix visual differences by randomly changing
CSS values. Instead, I inspect the element, compare its dimensions
with the design, and identify the actual source of the difference.
